# Almacenamiento y archivos

`academy-private` es un bucket privado. Admite JPEG, PNG, WebP, GIF y PDF hasta 20 MiB. La ruta física usa `team_id/user_id/UUID.ext`, independiente del nombre visible. La ruta de subida valida tamaño, MIME y firma inicial del archivo; si falla la inserción de metadatos, elimina el objeto recién subido con el cliente de servicio en servidor.

La biblioteca pagina recursos de 20 en 20. Las páginas generan URLs firmadas de 300 segundos para previsualización; la clave de servicio nunca sale al navegador. RLS y políticas de Storage exigen membresía activa del equipo; las socias solo pueden leer archivos referenciados por material publicado. `delete_unused_resource` bloquea el recurso, comprueba portadas, adjuntos y bloques de todas las revisiones, y solo entonces elimina sus metadatos. Un trigger bloquea la creación concurrente de nuevas referencias. La ruta de servidor elimina el objeto de Storage; si esa limpieza falla, `resource_deletion_jobs` conserva la ruta para reintento manual. Las URLs ya firmadas pueden seguir siendo válidas hasta cinco minutos. Los videos grandes se incrustan desde YouTube/Vimeo; alojamiento privado de video queda para una fase posterior.
